## 2. Requisitos Não Funcionais

Os requisitos não funcionais definem critérios de qualidade, desempenho e restrições técnicas do sistema IFSPORT.

### RNF01 — Desempenho
O sistema deve responder às ações dos usuários — como login, visualização do feed e inscrições — em tempo adequado, sem apresentar travamentos ou lentidão perceptível.

### RNF02 — Segurança dos Dados
O sistema deve garantir a proteção dos dados pessoais dos alunos e servidores, mantendo as senhas armazenadas de forma segura e restringindo o acesso ao painel administrativo a usuários autorizados.

### RNF03 — Usabilidade
O sistema deve possuir uma interface clara e organizada, permitindo que alunos realizem cadastros, inscrições e consultas de informações esportivas de maneira simples e intuitiva.

### RNF04 — Compatibilidade
O sistema deve funcionar corretamente em computadores e dispositivos móveis, utilizando os principais navegadores disponíveis, sem perda de funcionalidades.

### RNF05 — Confiabilidade
O sistema deve assegurar que inscrições, notificações, postagens e dados dos usuários sejam armazenados corretamente, evitando perda ou inconsistência de informações.

### RNF06 — Manutenibilidade
O sistema deve possibilitar a inclusão de novas modalidades esportivas, eventos e comunicados, bem como correções e melhorias, sem exigir grandes alterações na estrutura do sistema.

---

## 3. Considerações Finais

Os requisitos apresentados orientam o desenvolvimento do IFSPORT, servindo como base para a definição da arquitetura do sistema, do modelo de dados e das funcionalidades a serem implementadas.
