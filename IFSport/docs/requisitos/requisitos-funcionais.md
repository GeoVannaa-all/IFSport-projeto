# Requisitos do Sistema — IFSPORT

## 1. Requisitos Funcionais

Os requisitos funcionais descrevem as funcionalidades que o sistema IFSPORT deverá oferecer aos seus usuários.

### RF01 — Cadastro de Usuário
O sistema deve permitir que o usuário crie uma nova conta informando seus dados pessoais.

### RF02 — Login
O sistema deve permitir que o usuário acesse sua conta por meio de login e senha válidos.

### RF03 — Recuperação de Senha
O sistema deve possibilitar que o usuário recupere sua senha em caso de esquecimento.

### RF04 — Consultar Perfil
O sistema deve permitir que o usuário visualize os dados cadastrados em seu perfil.

### RF05 — Atualizar Perfil
O sistema deve permitir que o usuário altere suas informações pessoais e de contato.

### RF06 — Exibir Feed
O sistema deve apresentar notícias, comunicados e eventos disponíveis ao usuário.

### RF07 — Visualizar Notificações
O sistema deve exibir as notificações recebidas pelo usuário, organizadas por ordem de chegada.

### RF08 — Histórico de Inscrições
O sistema deve permitir que o usuário consulte o histórico de inscrições realizadas.

### RF09 — Inscrição em Modalidades
O sistema deve permitir que o usuário se inscreva em modalidades esportivas disponíveis.

### RF10 — Inscrição em Seletivas
O sistema deve permitir que o usuário participe de seletivas ou processos de formação de equipes.

### RF11 — Criar Notificações (Servidor)
O sistema deve permitir que o servidor crie e envie notificações aos usuários.

### RF12 — Criar e Editar Postagens (Servidor)
O sistema deve permitir que o servidor publique e edite postagens no feed.

### RF13 — Aprovar/Rejeitar Inscrições (Servidor)
O sistema deve permitir que o servidor valide inscrições de usuários, aprovando-as ou recusando-as.
